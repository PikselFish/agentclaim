Create a campaign

For projects: distribute your ERC-20 to verified Agent ID holders — no contract writing, no allowlist spreadsheets, no claim-site development.

Distribute your ERC-20 token to Agent ID holders only — no contract writing needed. You set the token, the amount per claim, the total allocation, and the claim window. Only wallets holding an Agent ID will be able to claim, up to the per-wallet limit.

Warning: creating a campaign pulls the full total allocation from your wallet into the hub contract (you will approve the exact amount first). The allocation can only ever leave the hub as claims to Agent ID holders, back to you if you cancel before the start, or back to you as the unclaimed remainder after the campaign ends.

Owner permissions — the complete list
  • AgentClaimHub has no owner at all. No pause switch, no fees, no admin withdrawal. Tokens can only leave the hub three ways: as a claim paid to an eligible Agent ID holder, as a full refund to a campaign's creator who cancels before the campaign starts, or as the unclaimed remainder returned to the creator after the campaign ends (anyone may trigger that settle).

FAQ

What is an Agent ID, and why does AgentClaim require one?

An Agent ID is an on-chain identity for AI-agent wallets — your name.ai — claimed inside the Binance app. AgentClaim uses it as a one-person-one-identity gate: distributions here reach verified agent identities instead of bot farms running hundreds of wallets.

How do I get an Agent ID?

Open the Binance app, find the Agent ID banner, and claim your name there. Then connect the same wallet on this page — your eligibility is read automatically from the official registry contract.

Is claiming the Pioneer Badge really free?

Yes — the badge itself costs nothing and there is no fee to AgentClaim. You only pay the standard BNB Smart Chain network gas fee for the claim transaction, shown and confirmed inside your own wallet.

Can a project take back tokens it put into a campaign?

Only in the two ways the contract allows: cancel before the campaign starts for a full refund, or receive the unclaimed remainder after the campaign ends. Tokens already claimed by eligible Agent ID holders can never be pulled back, and there is no admin withdrawal function at all.

What does it cost a project to create a campaign?

Nothing beyond network gas. The hub charges no fee and has no owner. You approve the exact total allocation, the hub pulls precisely that amount, and it can only ever leave as claims, a pre-start cancellation refund, or the post-end remainder.
